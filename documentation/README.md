# Documentation Hub

This folder is the single home for operational docs, diagrams, and evaluation materials.

## Top-level files

- `architecture-overview.md`: runtime architecture, component boundaries, and request flow
- `architecture-decisions.md`: documented architecture decisions and rationale
- `deployment-google-cloud.md`: Google Cloud deployment procedures and release checks
- `branching-and-pr-policy.md`: branch model, pull-request process, and merge gates
- `security-baseline.md`: minimum security controls and operational expectations
- `release-checklist.md`: repeatable pre-merge and pre-release validation checklist
- `github-branch-protection-setup.md`: GitHub settings needed to enforce branch rules
- `operations-runbook.md`: health checks, incident triage, and rollback procedures
- `TECH_STACK_CLOUD.md`: high-level cloud and runtime stack reference

## Subfolders

- `diagrams/`: architecture images and diagram notes
- `validation/`: QUEST evaluation materials and rubric examples
