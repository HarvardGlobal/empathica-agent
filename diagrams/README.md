# Diagrams

This folder contains a clean, publishable architecture diagram package.

## Structure
- `source/`: editable diagram code
- `publish/`: publication-facing outline and copy

## Files
- `source/empathica-architecture.mmd`:
  Mermaid source diagram (editable)
- `publish/empathica-architecture-outline.md`:
  non-technical + medical-facing explanation for publication

## Notes
- Diagram is intentionally simple and technology-labeled.
- Connectors are designed for straight left-to-right flow.
- If rendering in Figma/FigJam, set connectors to orthogonal/elbow style to enforce no diagonal arrows.
